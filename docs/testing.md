# Тестирование

## Инструменты

- Vitest — запуск и изоляция тестов;
- React Testing Library — проверка React-компонентов через видимое поведение;
- `jest-dom` — DOM-матчеры;
- `user-event` и `fireEvent` — взаимодействие с интерфейсом;
- jsdom — DOM-окружение;
- V8 — измерение покрытия.

## Сценарии

### Сотрудники

- загрузка и ошибка API;
- поиск по имени и username без учёта регистра;
- отсутствие результатов;
- сортировка строковых полей и `groupId` в обоих направлениях;
- нормализация данных формы;
- успешное и неуспешное добавление и удаление;
- сохранение открытой формы и введённых значений при ошибке.

### Группы и навигация

- загрузка и ошибка API;
- сортировка участников, счётчики, пустые группы и сотрудники без группы;
- переходы между всеми страницами.

HTTP-граница подменяется mock-объектами, поэтому для тестов не нужен запущенный API.

монтирования React-приложения.

## Команды

```bash
npm run test:run
npm run test:coverage
npm run coverage:badges
```

`npm run test:coverage` создаёт text, HTML и JSON summary. Бейджи в `badges/` генерируются из того же JSON summary.
